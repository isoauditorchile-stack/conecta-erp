SECCIÓN 1: INTRODUCCIÓN

1.1 Acerca de CONECTA ERP

CONECTA ERP es un sistema integral de gestión empresarial diseñado específicamente para empresas latinoamericanas. Con 17 módulos principales y 107 submódulos especializados, CONECTA ERP cubre todas las necesidades de gestión de su organización, desde la administración básica hasta análisis avanzados de Business Intelligence.

Características Principales

Característica Descripción
Multi-empresa Gestione múltiples empresas desde una sola instalación con aislamiento total de datos
Multi-idioma Soporte para 8 idiomas (Español, Inglés, Portugués, Francés, Italiano, Alemán, Chino, Japonés)
Multi-país Adaptado para 9 países latinoamericanos con legislación específica de cada país
Integraciones SII (Chile), Previred (cotizaciones), Transbank, MercadoPago, PayPal, Stripe
API REST 7 endpoints completos para integración con sistemas externos
Seguridad 100% prepared statements, encriptación de contraseñas, control de acceso por roles

Módulos Incluidos

CONECTA ERP incluye los siguientes módulos especializados:

  2. 11 Ventas: Cotizaciones, pedidos, facturas, notas de crédito, comisiones
  3. 9 Compras: Órdenes de compra, recepciones, devoluciones, negociaciones

  7. 8 CRM: Leads, oportunidades, pipeline, marketing, seguimiento
  8. 7 Producción: Órdenes de producción, materia prima, proceso, calidad
  9. 7 Finanzas: Flujo de caja, bancos, cobranza, pagos, presupuesto
  10. 6 Logística: Transporte, rutas, flotas, tracking, costos
  11. 5 Marketing: Campañas, segmentación, contenido, métricas, automatización
  12. 18 Business Intelligence: Dashboards, análisis predictivo, machine learning
  13. 6 Configuración Avanzada: Parámetros, monedas, impuestos, sucursales
  14. 4 E-Commerce: Catálogo web, carrito, pedidos online, pagos
  15. 3 Proyectos: Gestión de proyectos, tareas, horas, gastos
  16. 2 Calidad: Inspecciones, no conformidades, acciones correctivas
  17. 2 Mantenimiento: Órdenes de mantenimiento, preventivo, activos

Mejores Prácticas

✅ TIPS de Gestión de Usuarios:
  • Asigne siempre el rol mínimo necesario (principio de menor privilegio)
  • Use nombres de usuario descriptivos que identifiquen al empleado (ej: juan.perez, no user001)
  • Requiera contraseñas fuertes (12+ caracteres, mayúsculas, minúsculas, números, símbolos)
  • Revise periódicamente usuarios inactivos y desactívelos para mejorar seguridad
  • No elimine usuarios, desactívelos para mantener historial de auditoría
  • Configure el idioma y zona horaria correctos para cada usuario

Errores Comunes y Soluciones

Error Causa Solución
"Email ya registrado" El email ingresado ya existe en la base de datos Use un email diferente o recupere la cuenta existente
"Username ya en uso" El nombre de usuario ya está tomado Elija un username diferente, agregue números o iniciales
"RUT inválido" El dígito verificador del RUT no coincide (solo Chile) Verifique que el RUT esté bien digitado, el sistema valida automáticamente
"Contraseña muy débil" La contraseña no cumple requisitos mínimos Use al menos 8 caracteres con mayúsculas, minúsculas y números
"Las contraseñas no coinciden" Contraseña y confirmación son diferentes Verifique que ambos campos tengan exactamente el mismo valor
