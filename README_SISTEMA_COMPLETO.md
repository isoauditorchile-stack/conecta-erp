## 🚀 INSTRUCCIONES DE INSTALACIÓN

### Paso 1: Configurar Base de Datos

1. Edita `includes/config.php` y configura tus credenciales:
```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'conectae_conectaerpbd');
define('DB_USER', 'conectae_conectaerpuser');
define('DB_PASS', 'pt125824caraud');
```

### Paso 2: Renombrar Archivos

Renombra los archivos `_new.php` a sus versiones finales:

```bash
mv index_new.php index.php
mv login_new.php login.php
mv register_new.php register.php
```

### Paso 3: Ejecutar el Instalador

1. Sube todos los archivos a tu servidor
2. Accede a: `http://tudominio.com/installer.php`
3. Haz clic en "Iniciar Instalación"
4. Espera a que se creen todas las tablas
5. ¡Listo! El sistema está instalado

### Paso 4: Primer Login

Usa las credenciales de administrador:
- **Email**: `auditorexchile@gmail.com`
- **Usuario**: `auditorex chile`
- **Contraseña**: `admin123`

**⚠️ IMPORTANTE**: Cambia la contraseña después del primer login.
